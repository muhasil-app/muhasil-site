# المحصل — الموقع وملفات التحميل

هذا المستودع فيه موقع برنامج «المحصل»، وتُنشر فيه ملفات التثبيت.

حمّل آخر إصدار من صفحة الإصدارات:

https://github.com/muhasil-app/muhasil-site/releases/latest

الموقع صفحة ثابتة بلا أدوات بناء، تنشرها كلاودفلير تلقائياً من الفرع الرئيسي. بيانات التواصل في كائن الإعدادات أعلى الشيفرة في الصفحة:

```
CONFIG.whatsapp / CONFIG.email
```
